# 🔐 Phishing Email Detection & Awareness System

## 📌 Project Overview

This project focuses on analyzing phishing emails and identifying malicious indicators such as spoofed domains, social engineering techniques, and suspicious links. It also provides awareness guidelines to help users prevent phishing attacks.

---

## 🎯 Objectives

* Identify phishing indicators in email samples
* Classify emails as Safe / Suspicious / Phishing
* Understand attacker techniques
* Provide prevention strategies

---

## 🛠 Tools Used

* Public phishing datasets
* Email header analysis (basic)
* Browser inspection tools
* Documentation tools (MS Word / PDF)

## 🚨 Key Phishing Indicators Identified

* Spoofed email domains (e.g., paypa1.com)
* Generic greetings (Dear Customer)
* Urgent or threatening language
* Requests for sensitive information
* Suspicious or hidden links

---

## 🔎 Indicators of Compromise (IOC)

* Fake domains: `paypa1.com`, `peoples.com`
* Suspicious login links
* Urgent keywords: *“account locked”, “verify now”*
* Requests for confidential data (PIN, SSN)

## 🔐 Prevention Guidelines

* Do not share sensitive information via email
* Verify sender email addresses
* Avoid clicking unknown links
* Use official websites for login
* Enable Two-Factor Authentication (2FA)

---

## 🚀 Key Learnings

* Phishing attacks rely on social engineering
* Attackers exploit urgency and fear
* User awareness is critical for prevention

---

## 📢 Conclusion

This project demonstrates how phishing emails can be identified using basic analysis techniques. It highlights the importance of cybersecurity awareness and proactive defense strategies.
